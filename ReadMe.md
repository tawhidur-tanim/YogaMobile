# Yoga App (d’Yoga)

The Yoga App (d’Yoga) is a mobile application for managing and booking yoga classes.  
It consists of two connected applications:

- **Admin App** – used by instructors to create and manage yoga courses and class schedules  
- **Customer App** – used by customers to browse, filter, book, and check out yoga classes  

The application is built using **Android (Java)** and **React Native**, with **Firebase** providing authentication and cloud-based data storage.

## Technology Used

- Android (Java) – Admin application  
- React Native (Expo) – Customer application  
- Firebase Authentication  
- Firebase Firestore (Cloud Database)

---

## Installation

The repository contains two main folders:

1. **dyoga** – Admin application (Android Studio)  
2. **dyogaCustomer** – Customer application (React Native)

---

### dyoga (Admin App)

**Requirements**
- Android Studio  
- Android emulator or physical Android device  

Open the `/dyoga` folder in Android Studio, allow the project to build, and run it on an emulator or physical device.

---

### dyogaCustomer (Customer App)

**Requirements**
- Node.js and npm  
- Android or iOS emulator  
- Visual Studio Code (recommended)
